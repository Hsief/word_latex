# WordLatexVSTO 1.1.2

本次更新针对 LaTeX 转 Word 公式后残留 `$`、反斜杠，以及公式替换范围错位的问题。

## 更新内容

- 修正 Word 文本偏移与实际文档范围之间的定位，替换前核对完整的公式及定界符。
- 修正单美元、双美元定界符误配和未闭合定界符处理，阻止公式跨表格单元格配对。
- 改进插入失败时的恢复处理，避免在未清理的插入内容之前再次复制原文。
- 对无法可靠定位或转换的公式保留原文并报告错误，便于核对原始公式。
- 保持选区所属的正文、页眉或脚注范围；重复转换含有原生公式的选区时，不再将整段内容当作裸 LaTeX。
- 补充转换器和扫描器回归检查。
- 同步程序集、VSTO 清单与安装器版本为 1.1.2。
- 发布流程保留历史 Release 和标签；已发布版本的安装包不再被其他提交覆盖。

## 安装与使用

1. 保存文档并关闭所有 Word 窗口。
2. 下载并运行本页的 `WordLatexVSTO_Setup.exe`，随后重新打开 Word。
3. 打开包含完整 LaTeX 源码的文档，在“论文工具”中执行转换。

修订模式开启、公式范围内含未处理修订，或源码中混入域、隐藏文字、已有公式对象时，插件会保留原文并说明原因。

如果旧版已经导致公式源码或正文缺失，请先使用撤销、原始文档或历史版本恢复完整内容，再用新版转换；缺失的原文无法根据残留字符自动还原。

## 构建与验证范围

发布流程在 Windows 上验证 PowerShell 脚本语法，编译 .NET Framework 4.8 Release，运行核心转换器与扫描器回归测试，再生成 EXE、MSI 和 ZIP。仓库中的 `scripts/Test-InstalledAddin.ps1` 提供包含中文正文、既有公式、域、表格以及重复转换的桌面回归检查。Word 桌面端的实际排版、插件加载及文档内转换仍需在安装了 Microsoft Word 的环境中验证；核心测试不能替代 Word 实机测试。
